Three steps

How it works

From folder to shared link in under a minute.

  1. 01

    Select a folder

    Choose the directory you want to make available. Only that folder is served — never your entire Mac.

  2. 02

    Start hosting & share the link

    The backend starts the server and returns a URL. Copy it or open it directly on another device.

  3. 03

    Access & stop when finished

    Browse the files from another device on your network, then stop hosting to shut the server down immediately.

LocalShare

A small project built for personal file sharing and for learning how local servers, HTTP, and browser APIs fit together.

Security reminder: never share folders containing passwords, private keys, financial records, or anything else sensitive.
